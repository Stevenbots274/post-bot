# Telegram command/menu blueprint

## /start
Welcome message + main menu.

## /help
Explain:
- creating posts
- adding buttons
- previews
- publishing
- HTTPS URL button generation
- supported formatting

## /create
Start a new draft.

## /quickpublish
Start a fast text post. Text can be supplied after the command.

## /buttons
Open button builder.

## /templates
Open template menu.

## /settings
Open user settings.

## /cancel
Cancel current operation and return to main menu.
